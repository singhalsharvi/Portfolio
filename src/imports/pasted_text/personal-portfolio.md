Create a premium, modern, highly professional personal portfolio website for a young software developer and aspiring AI/ML engineer.

The website should feel **clean, sophisticated, impressive, and recruiter-friendly**, while still having a visually attractive and memorable design. Avoid generic portfolio templates and overly flashy designs.

### Overall Design

* Modern minimalist aesthetic with strong visual hierarchy
* Premium tech/startup-inspired look
* Dark theme as the primary theme, with subtle gradients and elegant accent colors
* Use plenty of whitespace and clean spacing
* High-quality typography with a bold modern sans-serif font
* Subtle glassmorphism, soft gradients, thin borders, and tasteful shadows
* Smooth micro-interactions and subtle animations
* Make the design feel polished rather than crowded
* Fully responsive for desktop, tablet, and mobile

### Hero Section

Create a powerful first impression.

Include:

* Large headline: **"Hi, I'm Sharvi."**
* Supporting headline: **"Software Developer | AI/ML Enthusiast | Problem Solver"**
* A short 2–3 line introduction focused on building impactful technology and solving real-world problems
* Primary CTA: **View My Work**
* Secondary CTA: **Let's Connect**
* GitHub and LinkedIn icons
* A visually interesting developer/technology-inspired element on the right side, such as an abstract 3D tech visualization, code-inspired graphic, or elegant animated shape
* Add a subtle animated background effect without making the page distracting

### About Me

Create a concise and visually engaging About section.

Include:

* Short professional introduction
* Education
* Interests in software development, AI/ML, and problem solving
* A few personal highlights displayed as elegant cards
* Avoid long paragraphs

### Skills

Create a visually impressive skills section divided into categories:

**Programming:** C++, Python, JavaScript, Kotlin
**Development:** HTML, CSS, React, Node.js, Firebase
**AI/ML:** Python, Machine Learning, Computer Vision, YOLO
**Tools:** Git, GitHub, VS Code, Figma

Use modern skill cards, icons, or compact visual indicators. Do not use exaggerated percentage skill bars.

### Featured Projects

Make this one of the strongest sections of the portfolio.

Display 3–4 projects as large premium project cards.

Each project card should include:

* Project image/visual
* Project name
* One-line description
* Technologies used
* GitHub button
* Live Demo button
* Subtle hover animation

Use projects such as:

1. **AgriSaarthi** — AI-powered agricultural assistance platform
2. **Crop Recommendation System**
3. **Plant Disease Detection** using YOLO/Computer Vision
4. Add a placeholder for another future project

Make the project cards visually distinct and emphasize real-world impact.

### DSA / Problem Solving

Add a compact section highlighting competitive programming and DSA progress.

Include:

* LeetCode profile
* GitHub profile
* DSA topics being practiced
* A clean statistics-style presentation

Keep it professional and avoid unnecessary gamification.

### Experience / Achievements

Create a timeline-style section for:

* Hackathons
* Open-source contributions
* Technical events
* Certifications
* Leadership / club activities
* Other notable achievements

Use elegant timeline cards with dates and short descriptions.

### Currently Learning

Add a small section titled **"Currently Exploring"** with items such as:

* Advanced Data Structures & Algorithms
* Machine Learning
* AI Engineering
* Full-Stack Development

Make it feel dynamic and forward-looking.

### Contact Section

Create a strong final CTA:

**"Let's build something meaningful together."**

Include:

* Email
* LinkedIn
* GitHub
* A simple contact form with Name, Email, Message
* Clear Send Message button

### Navigation

Create a sticky navigation bar with:

* Home
* About
* Skills
* Projects
* Experience
* Contact

Include a small **Download Resume** button.

Navigation should smoothly scroll to each section.

### Visual Style

Use:

* Premium dark background
* White/light typography
* One sophisticated accent color such as electric blue, violet, or cyan
* Subtle gradient effects
* Modern rounded cards
* Thin borders
* Elegant icons
* Minimal but meaningful animations
* Smooth scrolling
* Hover effects on buttons, cards, and links

### Important UX Requirements

* The portfolio must look professional enough for internship and software engineering applications.
* Prioritize readability and recruiter experience.
* Do not overcrowd the page.
* Do not use excessive animations.
* Do not use cheesy stock photos.
* Make the projects and technical skills the visual focus.
* Make every section feel connected to the overall design system.
* Ensure excellent mobile responsiveness.
* Add subtle entrance animations and hover interactions.
* Include accessible contrast and readable font sizes.

### Final Design Direction

The final result should look like a **premium software engineer portfolio from a top-tier tech candidate**, combining the aesthetics of a modern startup landing page with a professional developer portfolio.

The design should communicate:
**"Technical, ambitious, creative, polished, and capable of building real products."**
